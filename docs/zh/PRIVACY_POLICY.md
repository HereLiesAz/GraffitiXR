# GraffitiXR 隐私政策

**最后更新日期：** 2026-09-04

HereLiesAZ 将 GraffitiXR 应用程序构建为一个源代码可用（source-available）应用程序（许可条款详见代码仓库中的 LICENSE 和 docs/LICENSING.md）。本服务由 HereLiesAZ 免费提供，并旨在按原样使用。

此页面用于告知访问者如果有人决定使用我们的服务，我们关于收集、使用和披露个人信息的政策。

如果您选择使用我们的服务，则您同意与本政策相关的信息收集和使用。我们收集的个人信息用于提供和改进服务。除了本隐私政策中描述的情况外，我们不会与任何人使用或分享您的信息。

## 信息收集和使用

为了获得更好的体验，在使用我们的服务时，我们可能要求您向我们提供某些个人身份信息，包括但不限于：

*   **相机数据：** 该应用程序需要访问您设备的相机以显示增强现实 (AR) 视图、覆盖模式以及捕获项目目标的图像。相机数据在您的设备上本地处理，除非您明确选择共享项目文件，否则不会传输到我们的服务器。
*   **存储 / 照片：** 我们需要访问您的设备存储（读取/写入外部存储或照片库）以加载覆盖图像、保存您的项目以及导出捕获的图像。
*   **位置数据（可选）：** 如果您授予位置权限，该应用程序可能会收集 GPS 数据（纬度、经度、海拔高度）以对您的项目进行地理标记。这些数据本地保存在您的项目文件中。

## 崩溃报告（选择性开启）

默认情况下，不会因为崩溃而有任何内容离开您的设备。如果应用崩溃或从内部错误中恢复，会在您设备上的一个本地临时文件中写入一份报告，以便应用在您下次打开时向您显示"上次运行已崩溃"的提示——该文件不会自行离开设备。

除非您自己在**设置 > 崩溃报告**中开启，否则将该报告发送给我们的功能默认是关闭的。只有当您已经选择开启时，应用才会在下次启动时将该报告作为**公开 issue** 上传到本项目的 GitHub issue 跟踪器（github.com/HereLiesAz/GraffitiXR）。该报告仅包含以下内容：

*   崩溃是致命的（应用被终止）还是已恢复（被捕获且应用继续运行）；
*   崩溃发生的日期和时间；
*   您设备的制造商和型号，以及您的 Android 版本；
*   应用的版本名称；
*   异常的堆栈跟踪（stack trace）；以及
*   应用自身 logcat 输出的最后最多 1,000 行（仅限于本应用的进程——不是系统级日志）。

由于该报告是作为公开的 GitHub issue 提交的，其内容（包括上述设备和日志信息）对任何能查看本项目 issue 跟踪器的人都是可见的。只有在您对此感到放心的情况下才开启崩溃报告功能。您可以随时再次关闭此设置，这不会影响已经发生的崩溃。

## 服务提供商

由于以下原因，我们可能会雇用第三方公司和个人：

*   促进我们的服务；
*   代表我们提供服务；
*   执行与服务相关的服务；或者
*   协助我们分析如何使用我们的服务。

我们使用 **Google ML Kit** 进行主体分割（背景移除）。此处理在您的设备上本地进行。

## 更新检查

设置界面中有一个"检查更新"按钮。不会自动检查任何内容——只有当您按下它时才会检查。按下它会向 **GitHub API**（api.github.com）发出请求，以查询本项目的最新发行版本。GitHub 是我们无法控制的第三方，在该请求期间您的 IP 地址会对 GitHub 可见，就像您向 github.com 发出的任何网络请求一样。除此之外不会随该请求发送任何其他信息。

## 安全

我们重视您信任向我们提供您的个人信息，因此我们正在努力使用商业上可接受的方法来保护它。但请记住，通过互联网传输的方法或电子存储方法都不是 100% 安全和可靠的，我们无法保证其绝对的安全性。

## 指向其他网站的链接

本服务可能包含指向其他网站的链接。如果您点击第三方链接，您将被引导到该网站。请注意，这些外部网站不受我们运营。因此，我们强烈建议您查看这些网站的隐私政策。我们无法控制任何第三方网站或服务的内容、隐私政策或做法，也不承担任何责任。

## 儿童隐私

这些服务不针对 13 岁以下的任何人。我们不会故意收集 13 岁以下儿童的个人身份信息。如果我们发现 13 岁以下的儿童向我们提供了个人信息，我们会立即从我们的服务器中删除此信息。如果您是父母或监护人，并且您知道您的孩子向我们提供了个人信息，请联系我们，以便我们能够采取必要的行动。

## 本隐私政策的变更

我们可能会不时更新我们的隐私政策。因此，建议您定期查看此页面以了解任何更改。我们将通过在此页面上发布新的隐私政策来通知您任何更改。

本政策自 2024-01-01 起生效。

## 联系我们

如果您对我们的隐私政策有任何问题或建议，请随时通过 https://github.com/HereLiesAz/GraffitiXR/issues 与我们联系。
