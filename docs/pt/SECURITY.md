# Política de Segurança

Levamos a segurança a sério. Por se tratar de uma aplicação offline, a superfície de ataque é limitada, mas mantemos padrões rigorosos para a proteção de dados locais.

## Versões Suportadas

Atualmente, apenas o branch `main` e a versão mais recente publicada (release) recebem atualizações de segurança.

## Relatar uma Vulnerabilidade

Se você descobrir uma vulnerabilidade de segurança no GraffitiXR, por favor **não abra uma issue pública**.
Em vez disso, envie um relatório privado de vulnerabilidade (Security Advisory) através do GitHub, ou entre em contato conosco diretamente.
Faremos o possível para investigar o problema rapidamente e fornecer uma correção na próxima atualização.
